# Procedural Decision Tree & Random Forest from Scratch

A non-OOP implementation of Decision Trees and Random Forests in Python. The implementation uses recursive pure functions, NumPy, and standard Python dictionaries without classes or scikit-learn tree models.

## Repository Layout
- `tree_rf.py`: Core algorithm implementation (procedural dictionary trees, tree search, and random forest).
- `harness.py`: An actual test script that compares the implementation against a trusted reference and clearly reports pass or fail.
- `WRITEUP.md`: A 2–4 page document covering analytical aspects, regularization analysis, and ensemble mechanics.
